**Keep these for development:**

### Subagent Isolation (when building)
- Spawn focused tasks, don't give the main agent everything
- Use `sessions_spawn` for: heavy research, code generation, long-running builds
- Parallel sub-agents for independent tasks
- ⚠️ Tool scoping per agent doesn't exist yet (no `tools.subagents.tools.allow` in config schema)
- Available subagent config: `model`, `thinking`, `maxConcurrent`, `maxSpawnDepth`, `maxChildrenPerAgent`, `runTimeoutSeconds`, `archiveAfterMinutes`

### Session Initialization (when testing/iterating)
- Bootstrap files load at session start (can't prevent this, they're injected)
- On-demand memory retrieval via `memory_search()` — correct pattern
- MEMORY.md loads in main sessions (already does, keep it)
- Don't try to cache/override bootstrap injection — not a configurable feature

### What NOT to waste time on
- Caching system prompt files — not configurable in OpenClaw
- Tool allowlist per subagent — config path doesn't exist
